# 快速开始

本节帮助你快速了解 ADOFAI Expansion 的生态，并找到你需要的东西。

## 1. 使用在线工具

无需安装，直接打开[在线工具](../mods/online-tools/)页面即可在浏览器中使用：

- **noeffect** —— 去除关卡特效，方便预览与制谱
- **Re_ADOJAS** —— 基于 ADOFAI.JS 的关卡播放器

## 2. 寻找 Mod

在[项目总览](./projects.md)中按类别浏览开源项目，也可以直接访问：

- **GitHub Releases** —— 大部分 Mod 在仓库的 Releases 页面发布
- **[modrift.org](https://modrift.org)** —— 组织的 Mod 平台

## 3. 动手开发

如果你想开发 ADOFAI Mod：

1. 从 [ADOFAIModTemplate](https://github.com/adofaiex/ADOFAIModTemplate) 克隆模板开始
2. 查阅相关文档，例如 [ADOFAI-JS](https://github.com/adofaiex/ADOFAI-JS)（关卡库）或 [Sarcary](https://github.com/adofaiex/Sarcary)（Mod API）

## 4. 交流反馈

这是一个非常随性的组织。如果有任何问题，欢迎在对应仓库的 Issues 中与我们交流，或加入我们的 [Discord 服务器](https://discord.gg/ddndY4xXeK) 在线讨论。
