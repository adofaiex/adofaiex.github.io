# 关于 ADOFAI Expansion

**ADOFAI Expansion** 是一个专注于研究与扩展《冰与火之舞》(A Dance of Fire and Ice, ADOFAI) 功能的组织。

> An organization that researches and expands the functions of ADOFAI.

这里会出现一些关于 ADOFAI 的有趣仓库，涵盖但不限于 **Mod、Patch、Shader、Tool** 等类型。

这是一个非常随性的组织，**没有任何组织规则**。

- GitHub 主页：<https://github.com/adofaiex>
- 官网 / Mod 平台：<https://modrift.org>
- Discord 服务器：<https://discord.gg/ddndY4xXeK>

## 我们做什么

- **Mod** —— 修复、优化、特效、辅助等游戏模组
- **Patch** —— 对游戏的增强与修复补丁
- **Shader** —— 视觉效果相关的研究与实现
- **Tool** —— 谱面与关卡相关的各类工具和库
