# NoEffect：去除关卡特效

[NoEffect](/tools/noeffect/) 可以在浏览器中导入 ADOFAI 关卡文件，去除其中的视觉特效，再导出为新的关卡文件。

## 使用场景

- 练习时希望去掉干扰视线的特效
- 制谱时预览「干净」的版本
- 想要一个特效少、加载更快的谱面

## 使用步骤

1. 打开 [NoEffect](/tools/noeffect/)
2. 导入关卡文件
3. 执行特效去除
4. 导出处理后的关卡文件

## 注意事项

- 特效去除只影响视觉效果，不影响判定与音符时间
- 建议保留原始文件备份
