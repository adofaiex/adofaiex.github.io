# ADOFAI.EditorTweaks

> 编辑器与游戏优化 Mod，当前版本 `1.4.7`。
>
> 项目地址：<https://github.com/adofaiex/ADOFAI.EditorTweaks>

## 特性

- **数值输入框拖动调节**：可设置步长与小数位
- **装饰拖动**：Camera / CameraAspect 装饰拖动、移动吸附和轴心显示修复
- **视频背景同步**：普通游戏运行时视频背景与音乐同步
- **编辑器偏好即时保存**
- **缺图错误去重**
- **UMM 设置面板**

## 与相关项目的区别

它与 [ADOFAI.EditorTweaks.BetterZip](./adofai-editor-tweaks-betterzip.md)、[ADOFAI.EditorTweaks.ChartRendering](./adofai-editor-tweaks-chartrendering.md) **完全独立**，不依赖对方的 DLL、源码或配置。本项目**不包含**谱面视频渲染、FFmpeg、Web UI、压缩包处理或额外设置同步。

## 安装

从 [Releases](https://github.com/adofaiex/ADOFAI.EditorTweaks/releases) 下载发行包，解压到：

```text
Mods/ADOFAI.EditorTweaks/
```

启动游戏后通过 UMM 设置面板（默认 `Ctrl+F10`）配置。
