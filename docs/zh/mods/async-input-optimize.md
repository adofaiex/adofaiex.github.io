# AsyncInputOptimize

> 为 **ADOFAI 异步输入**优化的 Mod。通过 HarmonyLib 的 `HarmonyPatch` 修改 `Assembly-CSharp.dll` 相关代码实现。
>
> 项目地址：<https://github.com/adofaiex/AsyncInputOptimize>

> 本项目是从 **Cover** 独立出来的功能；旧版本已移动到 [AsyncInputOptimize_OLD](https://github.com/adofaiex/AsyncInputOptimize_OLD)。
