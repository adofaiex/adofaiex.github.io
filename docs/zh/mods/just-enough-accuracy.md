# JustEnoughAccuracy

> 新的**角度级精度判定**（JEA）——读取与官方判定相同的命中数据，但用自己固定的赋分表评分，与原判定**共存且互不影响**。支持查看判定细节并导出游玩数据。
>
> 项目地址：<https://github.com/adofaiex/JustEnoughAccuracy>

## 特性

1. **新的 `JEA` 精度** —— 独立于官方判定的附加精度
2. **详细结果查看器** —— 每关结束后可打开窗口，查看逐块细节，支持搜索与滚动浏览整个会话
3. **导出与分享** —— 将会话导出为 `.yaml` 文件或交互式 `.html` 图表

## 判定机制

JEA 是固定的**赋分制**判定：

- 每块的原始**角度偏差先归一化到参考 BPM**（`deviation × 100 / BPM`），因此任意谱面上相同的毫秒级时间误差得分一致
- 归一化偏差按**固定分档表**评分，相邻锚点之间**线性插值**——所以 95、97、98.4 等任意分值都可达，而不只是锚点值

| 归一化偏差 | 得分 |
| --- | --- |
| ≤ 1.7° | 100 |
| 2.0° | 96 |
| 2.4° | 92 |
| 2.8° | 88 |
| 3.2° | 84 |
| 3.6° | 80 |
| 4.0° | 75 |
| 4.5° | 70 |
| 5.0° | 62 |
| 5.5° | 54 |
| 6.0° | 46 |
| 6.6° | 36 |
| 7.2° | 26 |
| 8.0° | 15 |
| > 8.0° | 0 |

### 其它规则

- **连击**：连续得分 ≥ 50 的块构成连击。连击仅用于显示，**不参与乘法**，因此 JEA 精度上限为 100%
- **空按容忍**：镜像官方 `consecutiveMultipressCounter > 8` 规则——前 8 次连续空按被原谅，之后每次空按扣 -100 并重置连击
- **漏块 / 过载**：每个失败块记 -100

```
JEA Acc = TotalScore / (Tiles × 100)   （最多 4 位小数）
```

## 导出

导出文件写入 `<mod 目录>/reports`。

- 支持加载器：UnityModManager、MelonLoader、BepInEx
- 游戏版本：≥ 3.1.0
