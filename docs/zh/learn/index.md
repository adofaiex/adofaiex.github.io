# 学习路线

本站的教程采用**渐进式**组织方式，每个系列由循序渐进的章节组成，带你从零开始一步步完成实战。

## 开发教程

### 🎮 [Mod 开发](./mod/)
面向想为《冰与火之舞》开发 Mod 的开发者。

- 前置知识：**零基础也可以**（有《C# 基础速成》补课章），会一点 Git/GitHub 更好
- 流程：C# 基础速成（可选）→ 从这里开始 → 认识 UMM → 最小实例 → Harmony（Prefix / Postfix / Finalizer / Transpiler / Reverse Patch）→ 设置界面 → 进阶 → 发布与规范
- 最终产出：一个可以发布分享的 ADOFAI Mod

## 建议的学习方式

- 每个章节大约需要 10~20 分钟，请配合代码实操
- 阅读顺序建议从上到下，也可以按兴趣跳转
- 遇到问题可以在对应仓库的 Issues 中交流，这是个非常随性的组织
