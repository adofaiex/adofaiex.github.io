# Quick Start

This section helps you quickly understand the ADOFAI Expansion ecosystem and find what you need.

## 1. Use the online tools

No installation required — just open [Online Tools](../online-tools.md) and use them in your browser:

- **noeffect** —— remove level effects for preview and charting
- **Re_ADOJAS** —— an ADOFAI level player based on ADOFAI.JS

## 2. Find mods

Browse open-source projects by category in [Projects](./projects.md), or check out:

- **GitHub Releases** —— most mods are published in the Releases page of each repository
- **[modrift.org](https://modrift.org)** —— the organization's mod platform

## 3. Start developing

If you want to develop an ADOFAI mod:

1. Clone [ADOFAIModTemplate](https://github.com/adofaiex/ADOFAIModTemplate) as a starting point
2. Read related docs, such as [ADOFAI-JS](https://github.com/adofaiex/ADOFAI-JS) (level library) or [Sarcary](https://github.com/adofaiex/Sarcary) (mod API)

## 4. Feedback

This is a very casual organization. If you have any questions, feel free to open an Issue in the relevant repository, or join our [Discord server](https://discord.gg/ddndY4xXeK).
