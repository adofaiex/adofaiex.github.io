# 빠른 시작

ADOFAI Expansion 생태계를 빠르게 파악하고 필요한 것을 찾아보세요.

## 1. 온라인 도구 사용하기

설치 없이 [온라인 도구](../online-tools.md) 페이지를 열어 브라우저에서 바로 사용할 수 있습니다.

- **noeffect** —— 이펙트를 제거해 미리보기와 차트 제작에 활용
- **Re_ADOJAS** —— ADOFAI.JS 기반 ADOFAI 레벨 플레이어

## 2. 모드 찾기

[프로젝트](./projects.md)에서 카테고리별로 오픈소스 프로젝트를 둘러보세요. 또는:

- **GitHub Releases** —— 대부분의 모드는 각 저장소의 Releases 페이지에서 배포됩니다
- **[modrift.org](https://modrift.org)** —— 조직의 모드 플랫폼

## 3. 직접 개발하기

ADOFAI 모드를 개발하고 싶다면:

1. [ADOFAIModTemplate](https://github.com/adofaiex/ADOFAIModTemplate)을 복제해 시작하세요
2. [ADOFAI-JS](https://github.com/adofaiex/ADOFAI-JS)(레벨 라이브러리)나 [Sarcary](https://github.com/adofaiex/Sarcary)(모드 API) 문서를 참고하세요

## 4. 피드백

매우 자유로운 조직입니다. 궁금한 점이 있으면 해당 저장소의 Issues에서 자유롭게 문의하세요.
