# AsyncInputOptimize

> A Mod that optimizes **ADOFAI async input**. Implemented via HarmonyLib's `HarmonyPatch` modifying `Assembly-CSharp.dll` code.
>
> Project: <https://github.com/adofaiex/AsyncInputOptimize>

> This project was spun off from **Cover**; the old version has been moved to [AsyncInputOptimize_OLD](https://github.com/adofaiex/AsyncInputOptimize_OLD).
