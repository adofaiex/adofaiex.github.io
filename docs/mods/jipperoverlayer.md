# JipperOverlayer

> An ADOFAI in-game **screen overlay** Mod: real-time display of progress, accuracy, BPM, combo, and judgment info. Supports **Unity Mod Manager** and **MelonLoader**, with settings UI in English / Korean / Chinese.
>
> Project: <https://github.com/adofaiex/JipperOverlayer>

## Features

- **Real-time overlay**: progress, accuracy (Accuracy / XAccuracy), music/map time, checkpoint, best record
- **BPM display**: floor BPM, current BPM, KPS, with pseudo BPM detection
- **Combo counter**: animated combo display + color gradient
- **Judgment display**: Miss / Bad / Good / Perfect and other hit breakdowns
- **Time scaling**: current timing scale percentage
- **Attempt tracking**: per-map attempt count (persisted)
- **Progress bar**: visual progress indicator
- **Jongyeol mode**: extended overlay with FPS, status, death count, start position, timing analysis, hidden debug text
- **Two-player support**: separate display for each player in multiplayer
- **Text effects**: global shadow (TMP Underlay) and outline, RGBA color picker, width/softness sliders
- **Per-section fonts**: independent font and size per overlay position (Main / BPM / Judgement / Combo / Timing / Attempt)
- **UI patch toggles**: beta watermark, level name position, auto text rearrangement can be toggled independently
- **Color editor**: interactive gradient editor for all overlay colors
- **XPerfect integration**: optional enhanced perfect display (requires [XPerfect](https://github.com/8100print/XPerfect))

## Installation

### Unity Mod Manager

1. Install [UMM](https://www.nexusmods.com/site/mods/21)
2. Download the **UMM** version from [Releases](https://github.com/adofaiex/JipperOverlayer/releases)
3. Install via UMM, or extract to `ADOFAI/Mods/JipperOverlayer/`

### MelonLoader

1. Install [MelonLoader](https://melonwiki.xyz/)
2. Download the **MelonLoader** version
3. Extract to `ADOFAI/Mods/JipperOverlayer-melon/`
4. Press **F7** in-game to open settings (rebindable)

## Requirements

- Steam version of ADOFAI
- UnityModManager 0.22.14+ **or** MelonLoader
- Supports game versions v136 and v141+
