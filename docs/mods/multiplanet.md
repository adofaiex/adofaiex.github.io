# MultiPlanet

> Unlocks the planet count limit for MultiPlanet events in _A Dance of Fire and Ice_, supporting **2–8 planets** (official limit is 2–3).
>
> Project: <https://github.com/adofaiex/MultiPlanet>

## Features

- ✅ Unlocks the `planets` property of MultiPlanet events, supporting 2–8 planets
- ✅ Use a slider in the editor to adjust planet count (range 2–8)
- ✅ New MultiPlanet events auto-reset `planets` to 2 (avoids inheriting the previous event's value)
- ✅ Removes the editor warning for >3 planets
- ✅ Removes the hardcoded runtime limit
- 🆕 **Level converter**: convert any level to a multi-planet version (2–8 planets)

## Installation

1. Make sure [Unity Mod Manager](https://www.nexusmods.com/site/mods/21) is installed and ADOFAI mod support is enabled
2. Copy `MultiPlanet.dll` and `Info.json` to:

   ```
   \A Dance of Fire and Ice\Mods\MultiPlanet\
   ```

3. Launch the game and enable MultiPlanet in the Mod list

## Usage

### Using the MultiPlanet Event

1. Open the level editor
2. Add a **MultiPlanet** event to any track
3. In the properties panel, `planets` now shows as a **slider** (or number input), adjustable 2–8

### Level Converter

Convert any level to a multi-planet version (2–8 planets).
